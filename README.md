# בוט טלגרם ל-chabad.ai

בוט טלגרם שמעביר את השאלות שלך לאתר [chabad.ai](https://chabad.ai) ומחזיר לך את התשובה שלו.

**הבוט לא פונה לשום מקור אחר.** אין בו מודל AI משלו ואין בו חיפוש באינטרנט. הוא פותח את האתר בדפדפן ברקע, מקליד שם את השאלה ומעתיק את התשובה כמו שהיא.

הבוט רץ על המחשב שלך, ועונה כל עוד המחשב דלוק והבוט פועל.

## התקנה (פעם אחת, ב-Windows)

### 1. מה צריך להתקין
- [Python](https://www.python.org/downloads/). בזמן ההתקנה סמן את **Add Python to PATH**.
- [Google Chrome](https://www.google.com/chrome), אם הוא עוד לא מותקן.

### 2. מורידים את הקוד
בעמוד המאגר בגיטהאב לוחצים על **Code** ואז **Download ZIP**, ופורסים את הקובץ לתיקייה.

### 3. יוצרים בוט בטלגרם
1. בטלגרם מחפשים את **@BotFather** ושולחים לו `/newbot`.
2. בוחרים שם לבוט ושם משתמש שמסתיים ב-`bot`.
3. מעתיקים את הטוקן שהוא שולח (נראה בערך כך: `123456:ABC-xyz...`).

### 4. מתקינים
1. לוחצים פעמיים על `install_windows.bat` ומחכים שיסתיים.
2. פותחים את הקובץ `.env` בפנקס רשימות, ומדביקים את הטוקן אחרי `TELEGRAM_BOT_TOKEN=`.

### 5. מתחברים לאתר
1. לוחצים פעמיים על `login_windows.bat`.
2. ייפתח חלון Chrome. מתחברים בו ל-chabad.ai עם חשבון הגוגל.
3. כשרואים את תיבת הצ'אט, סוגרים את החלון.

ההתחברות נשמרת בתיקייה `browser_profile`, שלא עולה לגיטהאב. אם בעתיד הבוט אומר שפג תוקף ההתחברות, חוזרים על השלב הזה.

### 6. נועלים את הבוט רק לך
1. לוחצים פעמיים על `start_windows.bat`.
2. שולחים לבוט בטלגרם הודעה כלשהי. הוא יענה עם מספר הזיהוי שלך.
3. סוגרים את החלון השחור, ומכניסים את המספר בקובץ `.env` אחרי `ALLOWED_USER_IDS=`.
4. מפעילים שוב את `start_windows.bat`.

מעכשיו הבוט עונה רק לך.

## שימוש
- שולחים שאלה, והבוט מחזיר את התשובה של chabad.ai.
- `/new` פותח שיחה חדשה. השאלות באותה שיחה ממשיכות את ההקשר הקודם.
- `/debug` שולח צילום מסך של האתר כפי שהבוט רואה אותו, וגם את קוד העמוד.

כדי שהבוט יעבוד, החלון השחור של `start_windows.bat` צריך להישאר פתוח.

## אם משהו לא עובד
- **התשובה חלקית, ריקה או כוללת טקסט מיותר:** שלח `/debug`, והעבר את הקובץ `page.html` שמתקבל למי שמתחזק את הקוד. לפי הקובץ אפשר להגדיר בקובץ `.env` את `ANSWER_SELECTOR` ו-`INPUT_SELECTOR`, כך שהבוט יזהה במדויק את התשובה ואת תיבת הקלט באתר.
- **רוצים לראות מה הבוט עושה:** קובעים `HEADLESS=false` בקובץ `.env`.
- **תשובות ארוכות נחתכות באמצע:** מגדילים את `STABLE_SECONDS`, למשל ל-`8`.

## עדיף בעתיד: API
אם מפתחי chabad.ai יוסיפו כתובת API (שולחים שאלה ומקבלים תשובה), אפשר להחליף את הדפדפן בקריאה ישירה. ככה הבוט יהיה מהיר ויציב יותר, ויוכל לרוץ גם על שרת בענן בלי התחברות ידנית.
